#PetCareTracker

iOS-застосунок для обліку щоденного догляду за домашніми тваринами, контролю графіка годування та календаря вакцинацій.

# Призначення та користувач
Застосунок створений для власників домашніх улюбленців, яким потрібно фіксувати режим харчування (час, тип і розмір порції корму) та не пропускати планові щеплення й профілактичні процедури.

# Основні сценарії
1. Створення профілю домашнього улюбленця (ім'я, вид, вага, вік).
2. Фіксація годування із зазначенням часу, виду корму та обсягу порції в грамах.
3. Додавання запису про проведену вакцинацію та планування дати наступного щеплення.
4. Перегляд історії догляду за конкретною твариною та перевірка найближчих або прострочених вакцинацій.

# Ключові сутності предметної області
Тварина (`PetProfile`)** — профіль улюбленця, що зберігає основні характеристики та колекції записів догляду.
Запис годування (`FeedingRecord`)** — подія харчування із зазначенням корму, грамажу порції та часу годування.
Запис вакцинації (`VaccinationRecord`)** — інформація про назву вакцини, дату проведення та планову дату ревакцинації.
Тип тварини (`PetSpecies`)** — перелік видів тварин (собака, кіт, інше).
